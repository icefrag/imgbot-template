icefrag 开发手册

一、快速上手

1. 初始化环境

装一次, 以后所有项目通用:

  • uv(包管理器): pip install uv -i https://pypi.tuna.tsinghua.edu.cn/simple
  • 已装 Python 3.12+ 的话 uv 直接用它, 不再下载;
  • 解压骨架 zip 到任意目录, 比如 D:\scripts\我的挂机。

    • (机器上有 Python 就能用它装; 没有 Python 也行, uv sync 会自动从南大镜像下载);

    2. 安装依赖

    在骨架目录执行:

    uv sync

    骨架自带的两个 wheel 在 libs/ 里(脚手架 + 引擎), 从本地文件安装; 其余公共依赖自动从清华镜像拉。全程不需要访问 GitHub。

    3. 测试启动

    uv run console.py

    中控台是唯一入口(单开多开都是它): 鼠标悬停在目标窗口上按 F9 → 收编进表格并启动; 表格行按钮启停; 右侧日志流; 再按 F9 收编下一个即多开。 adb 端(模拟器/真机)自动发现设备, 无需收编。

    二、写你的业务

    4. business.py: 参数面板

    一个 dataclass = 全部业务参数, FIELD_META 声明中文名与控件类型, 中控台的设置弹窗自动生成(用户改值自动落盘 business.yaml):

    from dataclasses import dataclass

FIELD_META = {
    "attack_wait": ("等击杀秒数", "entry"),
    "max_kills":   ("最大击杀数(0=无限)", "entry"),
    "pick_coin":   ("捡金币", "combo:是|否"),
}

@dataclass
class BusinessConfig:
    attack_wait: float = 10.0
    max_kills: int = 0
    pick_coin: bool = True

    任务里 ctx.cfg.attack_wait 取当前值。

    5. task.py: 挂机逻辑

    main_task(ctx) 是任务主体, 顶层命令 from icefrag.dsl import * 直接用:

    from icefrag.dsl import *

RED = (51, 51, 204)                                  # #CC3333 的 BGR
MON_PTS = [Pt(0, 0, RED, 40), Pt(8, 0, RED, 40)]     # 多点找色点阵

def main_task(ctx):
    while not stopped():                             # 挂机循环自己写
        hit = find_multi_color((0, 0, 900, 640), MON_PTS)
        if not hit:
            log("场上无怪"); sleep((1000, 2000)); continue
        click(*hit)
        if wait_color_gone("CC3333-282828", timeout=10000):
            log("击杀"); shot("kill")                # 留痕到 logs/shots

    循环自己写, 返回 = 任务完成: main_task 只被框架调用一次, 正常返回即整个 任务完成收口。要挂机就自己写 while not stopped(): ...(F9 叫停循环即退); 预期内的失败(没找到怪/点击落空)在循环里 try/except 掉——那是业务; 冒出去的异常 框架才接管: 自动重开, 连败熔断。做一次性任务直接写直线代码, 不用任何技巧。

    命令权威表见本手册三章(签名由框架内省生成, 与代码不漂移)。 冷门动作走逃生舱: ctx.ops(图色门面)/ctx.dm(DmSoft 全量)/ctx.device(adb 方言)。

    6. 图色素材

    素材就是 PNG 和色值, 用你顺手的截图工具做, 放进 templates/ 即可: wait_pic("xx.png") / find_tap("xx.png") 按文件名引用。 找色类逻辑不需要素材, 直接写色值(吸管取色, 注意 BGR 序)。

    同源裁材: 屏幕截图的像素未必等于框架截屏的像素(后台/特殊渲染窗口)。 从 logs/shots/ 的留痕截图裁素材——那是框架眼里的画面, 同源必配。

    三、DSL 语法

    键鼠

    命令原型说明
    clickclick(x, y, jitter=None, human=None, settle=None)点击 (x, y)。默认拟人: 贝塞尔轨迹到位→随机停顿→落点抖动(默认见
    dblclickdblclick(x, y, jitter=None, human=None, settle=None)双击 (x, y), 参数同 click; adb 端两击带 80~120ms 间隔。
    dragdrag(x1, y1, x2, y2, ms=350)按住拖拽(列表滚动/滑块): window=按住左键插值拖, adb=原生 swipe。
    movemove(x, y)悬停(不点)。adb 端无悬停概念, 报错指路。
    keykey(s)按键/组合键: key("enter") / key("ctrl+s")(修饰键 ctrl/alt/shift/win)。
    type_texttype_text(text)打字进绑定目标(聊天/搜索/改名框), 中文可: window=当前键鼠通道逐字
    sleepsleep(ms)可中断睡眠: F9 按下立刻醒(代替 time.sleep 的傻等)。

    消息

    命令原型说明
    loglog(text, level='info')打一条日志(中控台日志面板/终端), level: info|warn|error。
    shotshot(tag='')截当前绑定目标一帧存 logs/shots/(月日_时分秒_目标_标签.png)留痕, 返回路径或 None。
    stoppedstopped()F9 停止键按下过吗 —— 挂机循环的退出条件: while not stopped(): ...

    找点(单帧)

    命令原型说明
    find_colorfind_color(color, region=None, tol=0)区域找全部色块。color="RRGGBB"(偏差给 tol, 或写 "RRGGBB-DRDGDB")。
    find_allfind_all(pic, region=None, threshold=None)单帧找全部同类图(列表项/多目标), 近邻去重。
    find_multi_colorfind_multi_color(rect, points, direction=0)多点找色(大漠 FindMultiColor 对应物): 锚点在 rect 内搜索, 全部相对
    existsexists(pic, region=None, threshold=None)

    复合动作

    命令原型说明
    find_tapfind_tap(pic, region=None, timeout=0, threshold=None, verify=None)找到就拟人点(贝塞尔轨迹+停顿)。timeout=0 单帧试; verify=点后必须
    tap_until_gonetap_until_gone(pic, region=None, timeout=10000, threshold=None)连点直到图消失(确定/领取类), 返回点击次数; 不出现返回 0。

    等待(超时返 None/False)

    命令原型说明
    wait_picwait_pic(pic, region=None, timeout=10000, threshold=None)等图出现, 返回 (中心x, 中心y, 分数); 超时自动截图留痕。
    wait_pic_anywait_pic_any(pics, region=None, timeout=10000, threshold=None)等一组模板任一出现, 返回 (名字, x, y, 分数); 超时 None。
    wait_pic_gonewait_pic_gone(pic, region=None, timeout=10000, threshold=None)等图消失(加载页结束判定)。
    wait_colorwait_color(color, region=None, timeout=10000)等某色出现(色比图快), 返回 (x, y) 或 None。偏差写进色串:
    wait_color_gonewait_color_gone(color, region=None, timeout=10000)等某色消失(等击杀/等加载), 消失 True / 超时 False。
    wait_textwait_text(text, region=None, timeout=10000)OCR 等文字出现("完成"提示类), 返回 (中心x, 中心y, 相似度) 或 None。

    识字 / 找字(OCR)

    命令原型说明
    ocrocr(region=None, fast=False)识字: OCR 读区域全文, 行间空格连接("任务名叫什么"用这个)。
    ocr_numbersocr_numbers(region=None)识数: OCR 全文后抠所有数字串(等级取 [0], 坐标取 [:2]); 没识到返回 []。
    find_strfind_str(text, region=None, min_ratio=0.7)找字(大漠 FindStr 风): OCR 定位 + 按序比例匹配, 返回 (x, y) 或 None,

    导航(需 task.py 声明表)

    命令原型说明
    gogo(name, timeout=120000)走到目标界面, 图自动带路(BFS)+迷路重定位自愈。到达 True / 超时安静
    atat(name)期望验证: 当前是否在指定界面(单帧一张锚点, 高频便宜; 迷路判别用 go)。

    看门狗

    命令原型说明
    progressprogress(note='')手动打一次进展点(看门狗信号; find/wait 命中与点击已自动打点)。

    四、全局配置

    总说明

    框架自己的配置在 scaffold.toml(与业务配置 business.py 分离): 通道/热键/拟人键鼠/ 运行策略/外观。改完重启中控台生效; 下表默认值与类型由框架内省生成, 说明为人工 注释, 键位增删会触发生成器对账报错——不会漂移。

    目标与通道

    键类型默认说明
    backendstr'window'目标端: "window"(PC 窗口) | "adb"(模拟器/真机)
    window_classstr''window 端热键收编的类名过滤串(空=不过滤); 收编到子控件时用它锁定
    displaystr'normal'截屏通道: normal 前台抓屏 | gdi 后台 PrintWindow(遮挡可截, 通用首选) | gdi2 兼容模式(慢但稳, gdi 截图不刷新时) | dx 潜影注入(3D 游戏)
    mousestr'normal'鼠标通道: normal SendInput 真鼠标(需前台) | windows PostMessage 后台 | windows2 dx 消息+虚拟光标锁(治点击坐标总偏) | dx 潜影
    keypadstr'normal'键盘通道: 同 mouse; windows=带扫描码消息按键, 只达读消息循环的窗口, 轮询型游戏免疫→换 dx+hook_keystate
    fake_activeboolFalse绑定后假激活(EnableFakeActive): 治"唯独点击无反应"的后台激活门槛, 需 dx 系通道
    hook_keystateboolFalse键状态钩子: 治"键盘消息无反应"(游戏轮询键态不读消息), 需键盘 dx 通道
    hide_moduleboolFalse注入件模块隐身: 反作弊扫进程模块时开, 需 dx 系通道
    adb_serialslist[str][]adb 端预置序列号列表(空=自动发现)
    hotkeystr'f9'启动热键(收编/再按停止): f1~f12 / pause / scrolllock / home / end / insert / delete
    pick_modestr'hover'收编模式: hover 拾鼠标下窗口 | focus 拾焦点子窗口(模拟器渲染窗)

    拟人键鼠(dsl click/dblclick 的默认)

    键类型默认说明
    human_mouseboolTrue拟人键鼠总开关: true=贝塞尔轨迹+随机停顿+落点抖动; false=瞬移急点(速度优先)
    click_jitterint3点击落点抖动 ±px(0=精确落点); 防每次点同一位的机器人特征
    click_settle_mslist[int][60, 160]点击到位停顿区间 ms, 每次取区间随机(人不是节拍器); 调用处可单次覆盖

    运行策略与外观

    键类型默认说明
    max_restartsint3任务异常自动重开次数上限, 连败熔断(可配 on_fuse 自救)
    idle_timeoutint0无进展看门狗秒数(0=关): find/wait 命中与点击算进展, 超时停任务留痕
    window_sizelist[int][1280, 800]中控台窗口尺寸 [宽, 高]
    left_ratiofloat0.45中控台左列(目标表)占宽比例 0~1
    themestr'darkly'ttkbootstrap 主题名(设置弹窗可热切)

    五、通道选择速查

    能力矩阵

    通道取值前台/后台占真键鼠适用与坑
    displaynormal前台—直接抓屏, 目标须可见不被遮挡, 最快最稳
    displaygdi后台—PrintWindow 让窗口自画进内存, 遮挡/被盖都能截, 通用首选
    displaygdi2后台—兼容模式慢但稳; gdi 截图不刷新/花屏时换它
    displaydx后台—潜影注入截帧(OpenGL 已通, D3D9 调试中, 不通明确报错); 需 bin/ 注入件(杀毒报毒是常态)
    mousenormal前台占SendInput 真鼠标, 兼容一切; 跑动时人不能碰机器
    mousewindows后台不占PostMessage 直投消息; tkinter 自绘类窗口不认(收编前先看清目标)
    mousewindows2后台不占dx 消息鼠标+GetCursorPos 虚拟光标锁, 治"点击坐标总落到真鼠标处"; 需注入件
    mousedx后台不占潜影注入, 检测面最小, 需注入件
    keypadnormal前台占SendInput 真键盘
    keypadwindows后台不占带扫描码消息按键(旧"死案"系误传, 已实现); 只达读消息循环的窗口, 轮询型游戏(GetAsyncKeyState)免疫
    keypaddx后台不占潜影注入, 需注入件; 轮询型目标配 hook_keystate

    选型口诀: 能 gdi+windows 全后台就全后台(测试/挂机两不误); 目标不认 PostMessage 点击再退 normal 前台; 3D 游戏上 dx。

    对症速查(设置弹窗"经典组合"同款, 点按即套用):

    症状配方(display · mouse · keypad)
    起步首选 · 普通窗口后台gdi · windows · windows
    移动/键盘正常, 唯独点击全无反应gdi · dx · windows + fake_active
    键盘消息全无反应(轮询型游戏)gdi · dx · dx + hook_keystate
    点击坐标总落到真鼠标处/偏移gdi · windows2 · windows
    GDI 截图黑屏/冻结(D3D/GL 渲染)dx · dx · windows

    六、长跑保障

    机制表

    机制干什么哪里调
    异常自动重开任务抛异常自动重启, 连败超限熔断躺平scaffold.toml max_restarts
    on_fuse 钩子熔断前给你一次自愈机会(重启游戏/重登), 写 task.py 里 def on_fuse(ctx) -> booltask.py
    无进展看门狗画面卡死没异常也逃不过, 超时自动停+截图scaffold.toml idle_timeout
    FatalErrorraise FatalError("封号") 致命场景直接停, 不白烧重开次数task.py
    截图留痕shot("标签") 与失败自动截图, 都进 logs/shots自动

    七、打包与升级

    打包 exe 发给别人

    uv run build_exe.py

    产出 dist/<你的名>-v<版本>.zip: 目标机零 Python, 解压即用; templates/ 与 scaffold.toml 摆 exe 旁, 用户可自行调参。 bin/ 注入件会被 Defender 报毒, 目标机需把解压目录加入杀毒排除——发给人时记得交代。

    升级脚手架

    作者在群里发新版时:

  • 下载新的两个 whl, 替换 libs/ 里的同名旧文件(文件名里的数字就是版本号);
  • pyproject 里 [tool.uv.sources] 两行 path 改成新文件名;
  • uv sync。

    • 不领新版就继续用旧的, 互不影响。
