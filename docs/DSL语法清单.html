imgbot-template DSL 语法清单

四条铁律

  1. 凡时间皆毫秒 — sleep(500)=半秒, timeout=10000=10 秒(各等待命令默认)。
  2. 找不到/超时返回 None 或 False, 不抛异常 — "没找到"是挂机常态; 真故障(窗口没了)由框架绑定层兜底自动重开/熔断。
  3. F9 停止贯穿一切 — sleep 与所有 wait 命令按下即醒即退。
  4. ctx 是逃生舱 — 冷门动作(wait_until/retry/swipe_find/read_number/ probe/check_points...)与窗口管理走 ctx.ops / ctx.dm / ctx.device。

task.py 骨架

from bot.dsl import *          # 唯一的前缀

def main_task(ctx):            # 总入口, 抛异常=本轮失败(框架自动重开)
    while not ctx.stop.is_set():
        hit = find_color("CC3333", tol=40)
        if not hit:
            sleep(1500)
            continue
        click(*hit[0])
        if wait_color_gone("CC3333-282828", timeout=10000):
            log("击杀")

完整示范: test/auto_farm/task.py(多点找色版自动打怪)。

键鼠

命令原型说明
clickclick(x, y)点击 (x, y)。window: 移动+左键; adb: tap。
dblclickdblclick(x, y)双击 (x, y)。
movemove(x, y)悬停(不点)。adb 端无悬停概念, 报错指路。
keykey(s)按键/组合键: key("enter") / key("ctrl+s")(修饰键 ctrl/alt/shift/win)。
sleepsleep(ms)可中断睡眠: F9 按下立刻醒(代替 time.sleep 的傻等)。

命令原型说明

等待(超时返 None/False)

命令原型说明
wait_picwait_pic(pic, region=None, timeout=10000, threshold=None)等图出现, 返回 (中心x, 中心y, 分数); 超时自动截图留痕。
wait_pic_anywait_pic_any(pics, region=None, timeout=10000, threshold=None)等一组模板任一出现, 返回 (名字, x, y, 分数); 超时 None。
wait_pic_gonewait_pic_gone(pic, region=None, timeout=10000, threshold=None)等图消失(加载页结束判定)。
wait_colorwait_color(color, region=None, timeout=10000)等某色出现(色比图快), 返回 (x, y) 或 None。偏差写进色串:
wait_color_gonewait_color_gone(color, region=None, timeout=10000)等某色消失(等击杀/等加载), 消失 True / 超时 False。
wait_textwait_text(text, region=None, timeout=10000)OCR 等文字出现("完成"提示类), 返回 (中心x, 中心y, 相似度) 或 None。
