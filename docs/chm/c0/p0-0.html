click

点击 (x, y)。默认拟人: 贝塞尔轨迹到位→随机停顿→落点抖动(默认见

原型

click(x, y, jitter=None, human=None, settle=None)
scaffold.toml 的 human_mouse/click_jitter/click_settle_ms)。
jitter: 落点 ±px(0=精确); human=False 瞬移急点(速度优先, 停顿固定,
不吃 settle); settle: 到位停顿 ms。adb 端=停顿前摇+抖动 tap。

示例

click(231, 347)                       # 拟人点击(轨迹+停顿+抖动), 默认见 scaffold.toml
click(231, 347, human=False)            # 瞬移急点(速度优先)
click(231, 347, jitter=0, settle=200)  # 精确落点, 到位停 200ms
