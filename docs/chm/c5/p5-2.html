find_str

找字(OCR 线): OCR 定位 + 按序比例匹配, 返回 (x, y) 或 None,

原型

find_str(text, region=None, min_ratio=0.7)
找到就能点。关键词 ≥4 字才稳(实测 7 字错 1 字仍命中); 2 字短词比例上限
低, 需缩 region 并降 min_ratio。

示例

hit = find_str("每日签到")                     # 找字位置 (x, y) | None
if hit: click(*hit)                  # 找到就能点
# 短词(2字)不稳: 缩 region + min_ratio=0.5
