adb 端上手

三步:

  • scaffold.toml 改 backend = "adb"(可选: adb_serials 预置白名单,
  • 启动模拟器/插真机, 终端 adb devices 能看到它;
  • uv run console.py —— 在线设备整表自动入列(不自动启动), 表格按行

    • 空=收所有在线设备); 启动/停止, 📷 开实时预览, 双击改名; 后开的模拟器点扫描设备按钮补捞。

    热键收编(F9)是 window 端专属概念, adb 端没有也不需要。任务代码(task.py) 与 PC 端同一套命令——换端不改脚本, 差异全在下面两张表里。
