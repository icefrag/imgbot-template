命令一览(22 个, 双端同构)

22 个 icefrag 命令 adb 端全体可用, 签名/返回与三章一字不差(同一处内省生成); 端行为差异已写进说明列。 大漠直通在 adb 端不可用(调用即报错指路)。用法示例见三章示例速查——命令同一套。

键鼠(拟人)

命令原型说明
clickclick(x, y, jitter=None, human=None, settle=None)点击 (x, y)。默认拟人: 贝塞尔轨迹到位→随机停顿→落点抖动(默认见
dblclickdblclick(x, y, jitter=None, human=None, settle=None)双击 (x, y), 参数同 click; adb 端两击带 80~120ms 间隔。
dragdrag(x1, y1, x2, y2, ms=350)按住拖拽(列表滚动/滑块): window=按住左键插值拖, adb=原生 swipe。
sleepsleep(ms)可中断睡眠: F9 按下立刻醒(代替 time.sleep 的傻等)。

消息

命令原型说明
loglog(text, level='info')打一条日志(中控台日志面板/终端), level: infowarnerror。
shotshot(tag='')截当前绑定目标一帧存 logs/shots/(月日_时分秒_目标_标签.png)留痕, 返回路径或 None。
stoppedstopped()F9 停止键按下过吗 —— 挂机循环的退出条件: while not stopped(): ...

找点(单帧)

命令原型说明
find_allfind_all(pic, region=None, threshold=None)单帧找全部同类图(列表项/多目标), 近邻去重。单个命中用大漠直通 FindPic。

复合动作

命令原型说明
find_tapfind_tap(pic, region=None, timeout=0, threshold=None, verify=None)找到就拟人点(贝塞尔轨迹+停顿)。timeout=0 单帧试; verify=点后必须
tap_until_gonetap_until_gone(pic, region=None, timeout=10000, threshold=None)连点直到图消失(确定/领取类), 返回点击次数; 不出现返回 0。

等待(超时返 None/False)

命令原型说明
wait_picwait_pic(pic, region=None, timeout=10000, threshold=None)等图出现, 返回 (中心x, 中心y, 分数); 超时自动截图留痕。
wait_pic_anywait_pic_any(pics, region=None, timeout=10000, threshold=None)等一组模板任一出现, 返回 (名字, x, y, 分数); 超时 None。
wait_pic_gonewait_pic_gone(pic, region=None, timeout=10000, threshold=None)等图消失(加载页结束判定)。
wait_colorwait_color(color, region=None, timeout=10000)等某色出现(色比图快), 返回 (x, y) 或 None。偏差写进色串:
wait_color_gonewait_color_gone(color, region=None, timeout=10000)等某色消失(等击杀/等加载), 消失 True / 超时 False。
wait_textwait_text(text, region=None, timeout=10000)OCR 等文字出现("完成"提示类), 返回 (中心x, 中心y, 相似度) 或 None。

ocr_numbersocr_numbers(region=None)识数: OCR 全文后抠所有数字串(等级取 [0], 坐标取 [:2]); 没识到返回 []。
