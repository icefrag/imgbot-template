task.py 顶部 from bot.dsl import * 后的顶层命令速查。

四条铁律

  1. 凡时间皆毫秒 — sleep(500)=半秒, timeout=10000=10 秒(各等待命令默认)。
  2. 找不到/超时返回 None 或 False, 不抛异常 — "没找到"是挂机常态; 真故障(窗口没了)由框架绑定层兜底自动重开/熔断。
  3. F9 停止贯穿一切 — sleep 与所有 wait 命令按下即醒即退。
  4. ctx 是逃生舱 — 冷门动作(wait_until/retry/swipe_find/read_number/ probe/check_points...)与窗口管理走 ctx.ops / ctx.dm / ctx.device。

task.py 骨架

from bot.dsl import *          # 唯一的前缀

def main_task(ctx):            # 总入口, 抛异常=本轮失败(框架自动重开)
    while not ctx.stop.is_set():
        hit = find_color("CC3333", tol=40)
        if not hit:
            sleep(1500)
            continue
        click(*hit[0])
        if wait_color_gone("CC3333-282828", timeout=10000):
            log("击杀")
